## ✨ Overview

Habit Tracker is a fast, minimalist web application designed to help users build habits, stay consistent, and track progress through clean visuals and intuitive interactions.

It focuses on simplicity, performance, and motivation — without requiring accounts or backend services.

---

## 🔗 Live Demo

👉 https://habit-tracker-srushthi.vercel.app/

---

## 🚀 Features

- ✅ Add, edit, and delete habits (up to 15 habits)
- 📅 Daily, weekly, and monthly tracking
- 📊 Animated progress graphs with legends
- 🔥 Streak tracking system
- 💾 LocalStorage data persistence
- 🌙 Light / Dark mode toggle
- 🎨 Dynamic backgrounds for different views
- 🤖 Basic pattern-based insights
- 📱 Fully responsive design

---

## 🧠 Design Philosophy

- ⚡ Fast and lightweight (no backend)
- 🔒 Privacy-focused (no user data collection)
- 🎯 Built for consistency and habit formation
- 📊 Visual feedback to keep users motivated
